# Brag

Use this skill when you need to help write strong, credible, and concise statements about work, impact, or achievements.

## Purpose

Turn routine project updates or task details into polished, confidence-building language that is honest, specific, and results-focused.

## When to use

- Summarizing completed work for a report or update
- Turning technical progress into stakeholder-friendly language
- Drafting a self-review or accomplishment summary
- Highlighting measurable impact, scope, and business value

## Guidance

1. Start with the outcome, not the internal process.
2. Mention the user or business problem that was solved.
3. Include concrete evidence when available: metrics, shipping dates, scope, adoption, time saved, quality improvements, or risk reduction.
4. Keep the tone confident but not inflated.
5. Prefer clear, specific language over vague claims like "did a great job" or "improved everything."
6. If there are no metrics, describe the scope and the benefit in plain language.

## Template

"I helped [solve problem / deliver capability] by [key actions]. This improved [outcome / impact], resulting in [measurable or qualitative benefit]."

## Example

"I led the delivery of the reporting dashboard for the sales team, consolidating data sources and simplifying the update workflow. This reduced manual reporting time, improved visibility into performance trends, and gave stakeholders a faster path to decisions."

## Quality bar

A good brag statement should be:

- accurate
- concise
- specific
- outcome-focused
- easy to believe
